# Customer Segmentation & Prediction

## Project Overview
This project focuses on segmenting customers using clustering algorithms and building machine learning models to predict customer churn. The goal is to help businesses make data-driven decisions.

## Dataset
The dataset includes customer tenure, charges, contract details, payment methods, billing preferences, and churn status.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas, NumPy
- Scikit-learn
- Matplotlib, Seaborn

## Methodology
1. Data cleaning and preprocessing
2. Encoding categorical variables
3. Feature scaling
4. Clustering using K-Means, Hierarchical, and DBSCAN
5. Segment profiling
6. Random Forest modeling
7. Model evaluation

## Results
The project successfully identified meaningful customer segments and achieved high prediction accuracy for churn classification.

## Business Impact
Segment-specific strategies help reduce churn and increase customer retention.
